# 繰り返し出てくる未説明の語を、その場で説明する — レビュアー向け手順

**事実の正誤は見ません。docs も引きません。** この層は全数監査済みです。

## なぜこの作業をするか（実測）

プレイテストで初学者が「説明がない」と実際に報告した語だけを対象にしています。
その語がコーパス全体でどう使われているかを数えたところ:

| 語 | 初級での使用 | その場で説明あり | **説明なし** |
|---|---|---|---|
| バインディング | 18問 | 2 | **16** |
| インスタンス | 16問 | 1 | **15** |
| ゾーン | 13問 | 3 | **10** |
| WAFカスタムルール | 7問 | 1 | **6** |

**設問は deep link で単独に開かれます。** 前の問題で説明したから次は省略、が成り立ちません。
各設問が自立している必要があります。

## やること

`targets[0].terms` に、その設問で説明なしに使われている語が入っています。
**1語ずつ、次の判断をしてください。**

### 判断1: その語は、答えを追うために要るか

要らないなら足さないでください。**足さない判断も仕事です。**

```
dq-001（Durable Objects の設問）の「インスタンス」
  → 設問自体が「インスタンスとは何か」を扱っている。
    解説が既に役割を説明しているなら、括弧書きは不要
```

### 判断2: 要るなら、標準の言い換えを使う

**自分で定義を考えないでください。** 下の言い換えをそのまま使います。
これらは docs か一般的な用語法で裏を取ってあります。

```
バインディング     → Workerから外部のリソースを使えるようにする宣言
インスタンス       → 1個分の実体
ゾーン             → Cloudflareに登録したドメイン
WAFカスタムルール  → 条件に当てはまったリクエストをブロックするなど、自分で書くルール
FaaS               → 関数単位でコードを実行するクラウドサービス
コールドスタート   → しばらく呼ばれていない処理を動かすときに待たされる時間
権威DNS            → そのドメインのDNSレコードについて正式な回答を返す側
Ruleset Engine     → WAFカスタムルールなどを評価する共通の基盤
プロパティ         → クラスに書いておく設定値
```

文脈に合わせて助詞や語尾は変えて構いませんが、**内容を足さないこと。**

### 判断3: どこに置くか

**その設問でその語が最初に出てくる層**に置きます。
設問文に出るなら設問文、解説が初出なら解説です。

括弧書きが自然に入らない場合は、無理に入れず `ok` にして
`rationale` に「置く場所が無い」と書いてください。

## やってはいけないこと

- **上の表にない語を足さないこと。** この作業の対象は表の語だけです
- **事実を足さないこと。** 標準の言い換え以外の説明を書かない
- **図のマーカー `{{diagram:N}}` を消さないこと**
- 正解肢の**文字数を大きく変えないこと（±15字以内）**
- **解説を書き換えないこと。** 括弧書きを1つ挿すだけです。
  文の構成を変えたくなったら、それは別の作業なので `ok` にして
  `rationale` にそう書いてください

## 出力

```json
[
  { "id": "kv-002", "optionIndex": 0,
    "verdict": "gloss | ok",
    "verifiedBy": "internal",
    "problem": "どの語を、なぜ足したか（ok なら足さなかった理由）",
    "rationale": "判断の根拠を1行",
    "edits": [{ "field": "explanation", "value": "..." }] }
]
```

### 【必須】担当した**全問**を1エントリずつ返すこと

足さないと判断したものも `verdict: "ok"` で返してください。
提出後に自分で被覆を確認:

```bash
node scripts/check-audit-coverage.mjs <あなたの入力> <あなたの出力>
```

- **`src/data/quizzes.json` を直接編集しないこと。** 並列書き込みで壊れます

## 最終メッセージ

**「何問中いくつ読んで、gloss が何件・ok が何件だったか」**
と、**足さないと判断した理由の代表例**を書いてください。
全問に足すのが正解ではありません。
